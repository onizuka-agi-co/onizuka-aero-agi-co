# Contributing

[日本語](#日本語) | [English](#english)

## 日本語

### 変更を提案する

1. 目的、対象ファイル、完了条件を明記して変更を提案します。
2. [使命とガバナンス](docs/company.md)と[データ方針](docs/data-policy.md)の範囲を確認します。
3. 実行したコマンド、ツールの版、出力、確認結果を記録します。
4. データやCADを変更した場合は、来歴、ライセンス、チェックサムを更新します。
5. 実出力と確認記録を添えてレビューを依頼します。

### 変更の境界

初期版の AX-01 KIRIN は架空のビジュアル資産です。現在の対象は形状の妥当性、境界、左右対称性、民生向けアーケードゲームの挙動です。初期版の範囲を広げる場合は、作業前にミッションと公開条件を定めてください。

`standard` と `longwing` は造形上のバリアントです。ゲームはCADから生成した同じメッシュを使います。ゲームの調整値を形状の測定値と混同しないでください。

### 権利とデータ

公開するのは、プロジェクトが公開を許可できる素材に限ります。第三者の素材を使う場合は、出所とライセンスを記載します。権利が不明な素材、個人情報、認証情報、秘密情報、第三者の非公開データは提出しないでください。

## English

### Propose a change

1. State the goal, affected files, and completion criteria.
2. Check the scope in [mission and governance](docs/company.md) and the [data policy](docs/data-policy.md).
3. Record the commands, tool versions, outputs, and checks you ran.
4. If you change data or CAD, update its provenance, license, and checksums.
5. Request review with the actual outputs and check records.

### Change boundaries

For the initial release, AX-01 KIRIN is a fictional visual asset. Current work covers shape validity, bounds, left-right symmetry, and civilian arcade gameplay. Define the mission and publication conditions before starting work that expands this release's scope.

`standard` and `longwing` are artistic variants. The game uses the same mesh generated from CAD. Keep game tuning values separate from geometry measurements.

### Rights and data

Submit only material the project is authorized to publish. Identify the source and license of any third-party material. Do not submit material with unclear rights, personal information, credentials, secrets, or third-party private data.
