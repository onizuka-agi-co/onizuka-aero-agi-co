# Company and project governance

[日本語](#日本語) | [English](#english)

## 日本語

### 使命

ONIZUKA AERO AGI Co. は、航空をテーマにした設計・検証・ゲーム制作をAIエージェントが進め、活動と成果をオープンデータとして公開する実験会社です。人間が使命と公開方針を定め、エージェントが再現可能な成果物、検証記録、来歴を整えます。初回は架空のAX-01 KIRIN r1を公開しました。現在は、人間が選んだC案をもとにしたトイ機体AX-01 SUZAKU r2の形状確認と民生向けゲームを扱っています。

### 意思決定権限

人間のミッション責任者が公開責任者として目的、作業範囲、公開方針、公開条件を事前に定めます。AIエージェントの担当はCAD設計、形状QA、ゲーム制作、データレビューです。事前承認された範囲の作業なら、エージェントが確認から公開まで完了できます。範囲、権利、公開方針の変更が必要な場合だけ、人間に判断を求めます。

### タスクの進め方

1. ミッション責任者が目的、完了条件、公開方針を定めます。
2. 担当エージェントが入力、利用権、現在の作業範囲との整合を確認します。
3. エージェントが作業を実行し、実際の出力、ツールの版、実行記録を保存します。
4. エージェントが出力を完了条件と照合し、未完了や失敗をその状態のまま記録します。
5. 事前承認された公開条件を満たした成果は、来歴とライセンスを付けて公開します。範囲外の作業や不明な権利が見つかった場合は、公開せず判断を求めます。

### 公開記録

作業の完了は実ファイルと確認記録で示します。エージェントの文章だけでは、成果、承認、売上、会議などの実績を証明できません。

## English

### Mission

ONIZUKA AERO AGI Co. is an experimental company for agent-led aviation-themed design, verification, and game production. AI agents create original digital assets, check their geometry, build civilian games, and publish the work and its data as open, reproducible records. A human mission owner sets the mission and publication policy. The first release introduced the fictional AX-01 KIRIN r1. Current work covers geometry checks and a civilian game for AX-01 SUZAKU r2, a toy design based on the human-selected concept C.

### Decision rights

The human mission owner is the release authority and sets the goals, scope, publication policy, and release conditions in advance. AI agents perform CAD design, geometry QA, game development, and data review. Within the pre-approved scope, agents can complete work, check it, and publish it. If scope, rights, or publication policy must change, they pause and ask the human owner to decide first.

### Task lifecycle

1. The mission owner defines the goal, completion criteria, and publication policy.
2. The assigned agent checks inputs, publication rights, and fit with the current scope.
3. The agent performs the work and saves the actual outputs, tool versions, and run records.
4. The agent compares outputs with the completion criteria and records pending or failed results as such.
5. Work that meets the pre-approved release conditions is published with provenance and license information. Out-of-scope work or unclear rights are held for a decision.

### Release records

Actual files and check records support completion claims. Agent-written text alone does not establish completed work, approval, revenue, or meetings.
